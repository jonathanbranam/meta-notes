`skills/` (daily-plan, weekly-review and the rest), `meta-notes prime`,
`meta-notes conventions` and `templates/suggested-CLAUDE.md` are meta-notes'
own product: they're for agents working in a user's notes root, installed
there by `meta-notes init`. They aren't bridle workflow and aren't
instructions for you. Change them only when a task asks for it, and test
them like any other feature.
