# Notes

Run `meta-notes prime` at the start of every session and follow it.

This is my personal notes root (`mode = "personal"`). `meta-notes prime`
describes the folders, notes, tasks, and commands. This file holds only my
own preferences; they override the guide where they differ. Edit them to
match how you live.

## My day

- My day runs 07:00 to 21:00, every day of the week, weekends included.
- I add appointments and planned time to the time block myself. Don't move
  or replace them when planning.
- There is no work lunch or workday shutdown. Leave room for meals, breaks
  and exercise.
- Weekends are for rest, family and projects at home; plan them lighter.

## Time log tags

Use the tags the guide lists. Untagged time counts as personal, so there's
no need to tag it `#personal`.

## End of the week

The weekly review and weekly plan skills run on Sunday and cover seven days.
